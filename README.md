# Power-BI-Assignment1-Data-Transformation-and-Data-Modeling
# E-Commerce Sales Analysis
# Overview
This assignment focuses on exploring and transforming e-commerce sales data using Power BI. It covers data cleaning, data transformation, merging tables, handling missing values and duplicates, sorting, filtering, grouping, aggregation and data modeling.
# Task Performed
* Imported List of Orders, Order Details, and Sales Target Datasets.
* Cleaned and transformed data using Power Query Editor.
* Changed data types and formatted columns.
* Created custom and conditional columns such as Profit Margin and Profit Status.
* Merged tables using Order ID.
* Identified and handled missing values and duplicate records.
* Applied sorting and filtering techniques.
* Performed grouping and aggregation.
* Created relationships between tables using appropriate columns.
  # Tools Used
* Microsoft Power BI
* Power Query Editor
 # Learning Outcome
  Gained practical experience in data transformation, data cleaning, table merging, aggregation and establishing relationships between tables in Power BI.
